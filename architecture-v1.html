Instinct V1 层参数

每个物理层均独立保存参数，因此参数量随层数线性增长；推理计算深度固定为 20。

Grouped-Query Attention

查询头多于 KV 头，降低 KV cache 占用。

  • Q / KV heads8 / 4
  • Head dimension96
  • Q/K RMSNorm2 × 96
  • Attention params/layer1,769,664

SwiGLU FFN

无 bias 的 gate、up 与 down 三个矩阵。

  • Hidden size768
  • Intermediate2,432
  • Expansion ratio3.167×
  • FFN params/layer5,603,328

Sequential Depth

所有 token 固定通过完整的 20 层网络。
