# 2012 ICPC 天津成都队员名单补录

大连理工大学教务处发布的 2012 年科技竞赛获奖统计汇编，直接列出了天津站、成都站和金华站的获奖等级及三人名单。原始 DOC 的下载来源保存在文件的 macOS 来源元数据中，链接当前仍返回 Microsoft Word 文档。

| 赛站 | 榜单队名 | 奖项 | 补录队员 | 对应依据 |
| --- | --- | --- | --- | --- |
| 天津 | Solo | 金牌 | 孙木鑫、王琳、张璨 | 汇编中天津站唯一金牌名单，对应榜单唯一金牌队 |
| 天津 | H$H/乱码 | 银牌 | 胡骏、孙崇林、洪祈泽 | 汇编中天津站唯一银牌名单，对应榜单唯一银牌队 |
| 成都 | Gospel | 银牌 | 孙木鑫、王琳、张璨 | 汇编中成都站唯一银牌名单，对应榜单唯一银牌队 |

金华站汇编列出董华磊、杨文冕、赵汉光获得铜牌，但 RankLand 榜单中大连理工大学有 `IBN5100` 和 `知识与历史的半兽 (Last Episode)` 两支铜牌队。现有证据不能把这组三人唯一对应到其中一队，因此本批次不补录金华站队员。

长春部分的标题是“2012 年 ACM/ICPC 长春全国邀请赛”，不是 2012 长春亚洲区域赛，因此不用于区域赛队员补录。
