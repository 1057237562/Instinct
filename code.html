def __init__(self, hidden_size=768, num_hidden_layers=8, use_moe=False, **kwargs): super().__init__(**kwargs) self.hidden_size = hidden_size self.num_hidden_layers = num_hidden_layers self.use_moe = use_moe self.vocab_size = kwargs.get("vocab_size", 6400) self.max_position_embeddings = 32768 self.rope_theta = 1e6 # RoPE base self.tie_word_embeddings = True # shared LM head

Forward, layer by layer

The real loop — it also branches to torch.utils.checkpoint when use_grad_checkpoint==2, accumulates MoE aux_loss, and fires exit_check_fn for early exit.

for layer, past_key_value in zip(self.layers, past_key_values): if self.config.use_grad_checkpoint == 2 and self.training: hidden_states, present = torch.utils.checkpoint.checkpoint( layer, hidden_states, position_embeddings, past_key_value, use_cache, attention_mask, use_reentrant=False) else: hidden_states, present = layer(hidden_states, position_embeddings, past_key_value=past_key_value, use_cache=use_cache, attention_mask=attention_mask) presents.append(present)

GatedDeltaNet — linear attention

Replaces softmax attention with a fixed-size state matrix S — S ← g·S + β·k·vᵀ, read via o = qᵀ·S. Every 4th layer is full attention, conv kernel 4, L2-norm Q/K. Chunked training (chunk 128) with recurrent inference, no KV cache. 71M params.

# GatedDeltaNet — O(T) linear attention S = g * S + β * k @ v.T # state update o = q @ S # read output out = RMSNormGated(o, z) # gated output norm
71M Params Full Attn Every 4th Conv Kernel 4 Chunk 128 No KV Cache

MoE top-1 gate

Softmax scores over 4 experts, top-1 selection, optional renormalization (norm_topk_prob), zeroed output buffer.

x_flat = x.view(-1, hidden_dim) scores = F.softmax(self.gate(x_flat), dim=-1) topk_weight, topk_idx = torch.topk(scores, k=self.config.num_experts_per_tok, dim=-1, sorted=False) if self.config.norm_topk_prob: topk_weight = topk_weight / (topk_weight.sum(dim=-1, keepdim=True) + 1e-20) y = torch.zeros_like(x_flat)

LayerSkip-style early exit

Shared LM head across exit layers [4, 5, 6, 7]; training CE weight 0.3. At inference the model exits when max(softmax(lm_head(h))) ≥ threshold (default 0.9) — skipped layers’ KV slots are padded with None.

train_pretrain.py — the training loop

Mixed precision via autocast + GradScaler, loss / accumulation, gradient clipping every step.

with autocast_ctx: res = model(input_ids, labels=labels, early_exit=bool(args.early_exit)) loss = res.loss + res.aux_loss loss = loss / args.accumulation_steps scaler.scale(loss).backward() if step % args.accumulation_steps == 0: step_with_scaler(scaler, optimizer, model.parameters(), args.grad_clip)

train_grpo.py — advantage, no critic

Group-relative normalization across num_generations rollouts — zero value-network parameters.

grouped_rewards = rewards.view(-1, args.num_generations) mean_r = grouped_rewards.mean(dim=1).repeat_interleave(args.num_generations) std_r = grouped_rewards.std(dim=1, unbiased=False).repeat_interleave(args.num_generations) advantages = (rewards - mean_r) / (std_r + 1e-4)
Dataset Layer

From JSONL to Tokens

Five dataset classes in one file, each translating raw JSONL into padded token batches.

PretrainDataset

Input {"text": "..."} → bos-token wrap + pad-mask; -100 on padding so only real tokens count toward loss.

SFTDataset

Input {"conversations": [...]} → apply_chat_template; assistant-only labels (-100 on prompt).

DPODataset

Input {chosen, rejected} → chat-template both halves; batch interleaves chosen / rejected pairs.

RLAIFDataset

Input {"conversations"} → prompt = template[:-1] + generation prompt; answers come from rollout.

AgentRLDataset

Input {"conversations", "gt"} → tools parsed from the system message; multi-turn tool-call loops over 3 turns with assistant, tool_calls and tool roles.

PretrainDataset.__getitem__

Tokenize, wrap in bos/eos, right-pad, then blank out pad positions in the labels.

tokens = self.tokenizer(str(sample['text']), add_special_tokens=False, max_length=self.max_length - 2, truncation=True).input_ids tokens = [self.tokenizer.bos_token_id] + tokens + [self.tokenizer.eos_token_id] input_ids = tokens + [self.tokenizer.pad_token_id] * (self.max_length - len(tokens)) labels = input_ids.clone() labels[input_ids == self.tokenizer.pad_token_id] = -100 return input_ids, labels

SFTDataset.__getitem__

Pre-process chat, render the template, truncate, then build assistant-only labels.

conversations = pre_processing_chat(sample['conversations']) prompt = self.create_chat_prompt(conversations) prompt = post_processing_chat(prompt) input_ids = self.tokenizer(prompt).input_ids[:self.max_length] input_ids += [self.tokenizer.pad_token_id] * (self.max_length - len(input_ids)) labels = self.generate_labels(input_ids) return torch.tensor(input_ids, dtype=torch.long), torch.tensor(labels, dtype=torch.long)

Support Layer

The Modules Underneath

The shared machinery every trainer, model and rollout path leans on.

flash_attn_4.py

Flash Attention 4 fused kernels with an SDPA fallback; native GQA support throughout.

kv_cache_quant.py

fp32 / bf16 / fp16 / fp8_e4m3 / fp8_e5m2. Per-(batch, head) quantized cache halves decode bandwidth.

checkpointing.py

RecomputeAttention autograd.Function — backward re-runs attention, saving only Q/K/V plus the dropout RNG state.

trainer_cli.py

Shared 37-flag parser: --dtype, --param_dtype, --kv_cache_dtype, --use_moe, --use_looped, --optimizer adamw|adafactor|muon, --use_compile, --use_grad_checkpoint 0|1|2.

trainer_utils.py

init_model, lm_checkpoint, build_optimizer, LMForRewardModel — the glue shared by all 8 trainers.

rollout_engine.py

RolloutEngine factory — TorchRolloutEngine via model.generate, SGLangRolloutEngine via HTTP /generate.
