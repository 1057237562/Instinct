# 2009 ICPC 亚洲区域赛成绩补录清单

大连理工大学页面发表于 2010-01-20，但其列出的哈尔滨、合肥、宁波、上海、武汉五站均属于第 34 届、即 2009 赛季。比赛日期以 ICPC Global 当前保留的赛事元数据为准；校内页面的发布日期不作为比赛日期。原页面标题沿用“亚洲区预选赛”的旧称，表内记录实际对应五场现场区域赛，不是网络预选赛。

校内页面直接给出七条奖项、成员和赛站；页面正文中的姓名为“陈沣”，不是截图缩放后容易误读的“陈洋”。奖项按项目既有口径归一化：银奖为银牌、铜奖为铜牌、荣誉奖为铁牌。

武汉站公开榜单只有一条大连理工大学记录，因此可以把校内页面唯一的武汉站名单对应到 `Bombee`；榜单正式排名为 `27 / 124`，含打星队伍的总榜位置为 `33 / 132`，解 4 题、罚时 436。ICPC Global 合肥站官方榜单也将大连理工大学参赛队列为 `Bombee`，因此合肥站同步采用该队名；本次未补录合肥站名次，名次继续留作待考。

其余四站未恢复到能够可靠对应本校记录的完整历史榜单，队名和名次明确留作待考。哈尔滨站的早期赛历曾列出 9 月暂定日期，ICPC Global 当前赛事元数据及同期比赛报道均指向最终举行日 2009-11-08，本批次采用最终日期。

本次使用独立批次 `icpc-official-dlut-2009-recovery-20260924-v2`。v2 根据 ICPC Global 官方榜单将合肥站队名纠正为 `Bombee`，并可在已导入 v1 的数据库中按同一官方来源标识原位更新，避免产生重复记录。全量种子中武汉记录与已有 RankLand 记录合并，只补齐银牌、官方来源和候选成员；其他六条新增。七组名单均进入管理员待确认队列，不因同一组选手跨站参赛而自动关联个人。
