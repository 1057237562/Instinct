Core Components

Every piece implemented from scratch in pure PyTorch — no high-level abstractions.

RMSNorm

Pre-Norm architecture. Root Mean Square normalization without re-centering — faster than LayerNorm with comparable stability.

RoPE (θ=1e6)

Rotary Position Embeddings encode relative positions through rotation matrices. Supports YaRN extrapolation for context lengths beyond 32K.

SwiGLU Activation

Gated Linear Unit with Swish activation. Intermediate size = ceil(dim × π / 64) × 64 — data-driven sizing.

GQA + GatedDeltaNet

Two attention mechanisms in one model. Full-attention layers use 8 Q-heads / 4 KV-heads with Flash Attention. Linear layers use GatedDeltaNet with L2-normed Q/K, short convolution, and O(1) state updates.

MoE Routing

Each token is routed to exactly 1 expert via a learned router with load-balancing auxiliary loss. No shared expert — aligned with Qwen3-MoE style. At inference, only 64M of 198M parameters are active.

# Router gate for top-1 expert selection scores = router(hidden_states) # (batch, seq, n_experts) weights, indices = scores.topk(k=1, dim=-1) weights = weights.softmax(dim=-1) output = dispatch_and_combine(hidden_states, weights, indices)

Inference Optimization

Early Exit (LayerSkip)

Dynamic per-token exit via shared LM head — zero auxiliary parameters. Stop decoding at intermediate layers when the model is confident.

Per-layer exit with callback

MiniMindModel.forward() accepts an exit_check_fn callback. At each layer, the model calls it with the current hidden state. If it returns True, the model stops — zero-padding KV for skipped layers. The callback is injected by MiniMindForCausalLM, which has access to the shared LM head.

# In MiniMindModel.forward(): for layer in blocks: h = layer(h, past_kv=pkvs[i]) if exit_check_fn is not None: normed = rmsnorm(h) if exit_check_fn(len(presents), normed): presents += [None] * remaining # zero-pad KV return normed, presents # stop early # In MiniMindForCausalLM.forward(): def check(layer, normed): if layer not in exit_layers: return False probs = softmax(lm_head(normed)) return probs.max() ≥ threshold
CALM-style confidence Shared LM head Zero extra params

Three forward() branches

Training

early_exit=True + labels — runs all 8 layers, computes CE loss at layers 4-7 via shared LM head. Teaches early layers to produce good logits. Weighted by early_exit_loss_weight (0.3).

Dynamic Exit

early_exit=True + no labels — injects exit_check_fn into model loop. Stops at first layer where max(softmax(lm_head(h))) ≥ threshold. Real compute savings — skipped layers never run.

Normal

early_exit=False — standard 8-layer forward pass (unchanged).

KV cache: None-padded for skipped layers

When a token exits at layer k, layers k+1 through 8 are skipped. Their KV entries are set to None. On the next token, those layers see past_key_value=None and compute fresh KV — attending to previously early-exited tokens via their newly generated (fresh) key/value projections, not cached ones from the skipped pass.

# Token exits at layer 5 → KV cache has 8 entries: presents = [kv1, kv2, kv3, kv4, kv5, None, None, None] # Next token: layers 6-8 see None → compute fresh
# Training: add early exit loss to teach early layers python train_pretrain.py --early_exit 1 # Inference: dynamic per-token exit (real speedup) python eval_llm.py --weight full_sft --early_exit 1 --exit_threshold 0.9 # Aggressive mode (more speed, less quality) python eval_llm.py --weight full_sft --early_exit 1 --exit_threshold 0.7
Training Pipeline

From Zero to RL in 3 Stages

Every stage uses pure PyTorch. Checkpoint-resume at any point.

1

Pretrain

Next-token prediction on pretrain_t2t.jsonl. Builds world knowledge and language patterns from scratch.

python train_pretrain.py --from_weight none # or: torchrun --nproc_per_node N
pretrain_768.pth ~1.2h on 3090
2

Supervised Fine-Tuning

Instruction-tuning on sft_t2t.jsonl. Teaches chat formatting, tool calling, and assistant behavior.

python train_full_sft.py --from_weight pretrain # MUST load pretrained
full_sft_768.pth ~1.1h on 3090
3

Post-Training (Optional)

LoRA · DPO · PPO · GRPO · CISPO · Agentic RL · Knowledge Distillation

lora_768.pth dpo_768.pth ppo_actor_768.pth grpo_768.pth agent_768.pth

Resume from any checkpoint: --from_resume 1  — handles GPU count changes automatically

GatedDeltaNet — Linear Attention

Replaces the softmax bottleneck with a fixed-size state matrix S. Each token updates S via S ← g·S + β·k·vᵀ, and reads output via o = qᵀ·S. Training uses chunked parallelism (chunk size 128), while inference uses recurrent O(1) per-token updates — no KV cache needed for linear layers.

# GatedDeltaNet — O(T) linear attention S = g * S + β * k @ v.T # state update o = q @ S # read output out = RMSNormGated(o, z) # gated output norm
L2 Norm Q/K Short Conv (k=4) Chunked Training Recurrent Inference No KV Cache
