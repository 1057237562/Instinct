# 旧赛季 42 队名单 Archive.org 核查

本轮按此前圈定的 42 支旧赛季队伍逐项检查 Internet Archive、赛站旧域名、ICPC Global 公开页、学校新闻/获奖汇编及可检索网页索引。只接受“同一场比赛 + 同一队名 + 明确成员”的证据；同名队跨赛站、同一批队员参加过其他比赛、学校总名额和注册账号都不用于补录。

结果是新增确认 1 队：2014 北京站 `临时变量`。其余 41 队仍没有满足标准的公开名单，继续留在待确认队列。

## 未采用的推断

- 2014 东北地区赛等校内报道虽然列出若干三人组合，但没有把这些组合与鞍山、牡丹江各队名逐一对应，不能拿奖项相近代替同场队名证据。
- 2015、2016 的其他赛站新闻列出过部分成员，不能反推 `余音`、`夏洛特`、`lingering_sound` 等队在目标赛站仍是同一阵容。
- ICPC Global 的旧赛季公开 standings 接口含队伍 ID，但成员接口需要授权；公开 accepted-team 接口对这些赛季关闭，不能据队伍 ID补出名单。
- Codeforces Gym/注册镜像中的幽灵账号只是队伍参赛入口，不是三名选手身份。
