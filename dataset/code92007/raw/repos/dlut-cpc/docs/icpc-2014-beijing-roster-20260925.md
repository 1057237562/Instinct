# 2014 ICPC 北京站“临时变量”名单补录

本次只补录 2014 北京站 `临时变量` 一队：邵华、刘博、许思航。成员证据和比赛结果证据来自两个独立页面，并在队名、学校和解题数上相互吻合。

## 成员证据

大连理工大学创新创业学院于 2014-11-20 发布“我校学子喜获第39届ACM-ICPC亚洲区北京站银牌”。原地址当前返回 404，Internet Archive 的 CDX 索引也没有该正文快照；360 搜索索引仍保留原页面标题、地址、发布日期及以下摘要：

> 由我校学子邵华、刘博、许思航组成的临时变量队解出6题获得一枚银牌。

该摘要同时给出三名成员、队名、解题数和奖项，不需要按其他比赛或同名队伍外推。

## 证据边界

- 搜索索引摘要是已失效校内原文的残留，不等同于 Internet Archive 正文快照，因此来源优先级设为 70，并在来源名称中明确标注“搜索索引摘要”。
- 赛站快照只有学校、队名和成绩，没有队员字段；它用于确认索引摘要指向同一支参赛队，不能单独证明成员。
- 本名单只应用于 `rankland-5f4d9073f152f3bb6e67`。同一成员或相似队名出现在其他赛站时，不自动复用。
- 一次性修正只填补空名单；生产库若已由管理员确认或修改该成绩，初始化不会覆盖现有名单。
